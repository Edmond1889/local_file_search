# 회의 메모

내용 기준: 2026-11-03. 파일명은 기존 이름을 유지했다.

PDF·PPTX 본문을 팀원 모델로 인코딩·검색하고 SQLite 파일 정보와 연결했다.
이미지 파일·PPTX 내부 이미지는 임시 코사인 비교로 검색한다. 화면과 파일명에 임시 구현임을 표시했다.
현재 테스트는 임시 비교 검증을 포함해 26개다. 테스트에서는 모델 출력 대역을 사용하므로 검색 품질 검증과는 구분한다.

main 3542252의 DB 상대 import와 인코더 모델 공유를 반영했다. 루트 document_info.py는 제거했다.

팀에서 정할 일:

1. 누가 어떤 상황에서 파일을 찾는지 페르소나와 검색 시나리오를 정한다.
2. PDF·PPTX·HWP/HWPX 중 시연 필수 범위와 담당자를 정한다.
3. 스캔 PDF 처리 방법과 임시 이미지 유사도 코드를 교체할 담당자 구현을 확인한다.
4. 실제 문서와 질문을 모아 원하는 파일이 상위 결과에 나오는지 평가한다.
5. 벡터 저장·재실행 복원, DB 연결 종료와 통합 규격을 담당자와 맞춘다.

현재 데모 사용법과 미지원 형식은 [README](../../README.md)에 있다.
