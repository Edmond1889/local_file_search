# 코드 공부

이 자료는 GitHub에서 읽기 위한 `codex/study-docs` 브랜치에 보관한다. 개발 브랜치의 `study/` 제외 설정은 유지하며, 이 브랜치는 개발 브랜치에 병합하지 않는다. 로컬 공부 자료를 수정한 뒤에는 이 브랜치에도 변경을 반영해야 GitHub에서 최신 내용을 볼 수 있다.

현재 흐름은 [코드 읽는 순서](learn.md)와 [프로젝트 연결 순서](../README.md#분석과-검색-흐름)를 따른다.

[전체코드.ipynb](전체코드.ipynb), [전체코드.py](전체코드.py), [비유로 읽는 전체 코드](비유로_읽는_전체코드.md)는 **2026-11-03 당시 구현을 보존한 공부 자료**다. 현재 코드 사본이 아니다. 예전 DB 경로·임시 이미지 비교·Tkinter 화면이 남아 있어 현재 환경에서 그대로 실행하면 오류가 날 수 있다.

현재 앱을 실행하려면 프로젝트 루트에서 `python app.py --gui`를 사용한다. 기존 줄별 설명과 실험 결과는 이력으로 보존하며, 이번 재점검에서 전체 공부 자료를 현재 소스로 다시 생성하지는 않았다.

프로그램 사용법은 [README](../README.md), 회의·제출용 메모는 [notes](notes/README.md)에 있다.

[다른 사진을 섞은 이미지 검색 실험](image_search_check_2026-11-03/결과.md)은 당시 7장·8개 검색어 실험 기록이다. 재실행 스크립트는 현재 앱을 불러오므로 다시 실행한 결과를 과거 결과와 같은 것으로 취급하지 않는다.
